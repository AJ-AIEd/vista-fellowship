# Professional-learning studio: implementation and limits

The website is one environment for VISTA's professional-learning framework. Five arcs orient inquiry; the existing six-stage assessment cycle and its 15 pathways remain intact. Exploration, coaching, assessment auditing, and an independent competency baseline serve different purposes.

## Implemented

- Four entry paths, selectable support, real editable prototypes, responsive workspace and optional account overlay.
- Five educational purposes for external, teacher-controlled experiments. The teacher records a prediction and checks an actual output; no live AI response is generated or simulated.
- Exploration from any assessment stage and a direct return to that same stage, retaining the assessment and observations in one cycle.
- One emerging hypothesis per cycle, its origin, relevance, unresolved questions, learning outcomes, and teacher-authored status. Separate cycles can hold additional inquiries.
- Optional prompts connecting technology, subject knowledge, pedagogy and context. These are design prompts, not a validated measure of AI-TPACK or growth.
- Proposal notes and a downloadable human-conversation handoff, with no automatic sending.
- Existing local recovery, backups, annotations, before/after comparison and reports; additional notes are included in exports. Optional account copies require explicit saving and open as a new local cycle.

## Limits and decisions

The studio is not the independent Initial AI Competency Baseline. A supported session does not establish independent competence or growth. Research reading is currently a checking workflow, not a fully appraised research library. Experiments provide a transparent external copy-and-compare workflow, without vendor APIs or account-policy assurances. One hypothesis per cycle is intentionally lightweight; a multi-idea history is not yet implemented.

No institutional cohort dashboard, peer messaging, automated feedback or AI interpretation is represented as functional. Proposal notes do not grant authority to change curriculum. The legacy printable three-phase protocol has not been rewritten to resolve framework terminology. SAIL commercial-use rights and employment-related IP remain owner decisions.

The workspace supports English and Spanish. Public invitation and field-guide pages still need a complete Spanish edition. Password recovery delivery, physical-device testing and manual screen-reader testing remain outstanding. Optional accounts use existing backend ownership policies; password hardening and the legacy account conventions merit a separate review.

Private recordings, transcripts and identifiable case details are not included in the public build or repository. No student-learning benefit is claimed from interface changes or synthetic tests.
